# Ready, Set, Go!

Hi, my name is Bruno. I am a lifelong, dedicated student of recreational programming and have been continuously engaging with the Go language. I have been studying Go for about two years, and—inspired by the Rust handbook *100-exercises-to-learn-rust*—I decided to create my own, but focused on Go. My main goal is to help future Gophers learn while also improving my own skills. This will be a gradual and somewhat long-term process, as I need to balance writing this handbook with my undergraduate studies and research in psychology. I will keep discussions open in the repository so you can ask questions, and at the end of this README, I will include links to documentation and other tutorials that I consider highly valuable and personally recommend.

After carefully reading this book and completing the exercises, you will come away knowing:

- How to read and write idiomatic Go, without translating mentally from another language
- How Go handles errors, concurrency, and composition — the three things that make Go, Go
- Enough to be productive on a real Go codebase, not just toy examples

To get the most out of this handbook and successfully complete the exercises, I will guide you through setting up the development environment. I personally recommend using Neovim, although you can complete the exercises using literally any text editor (or even pen and paper, or punch cards); so, if you prefer a different editor, do not view this as an obstacle to completing all the exercises.

### Acknowledgements & Inspiration

This project draws inspiration from two excellent resources:

- [100 Exercises to Learn Rust](https://github.com/mainmatter/100-exercises-to-learn-rust) — the exercise-driven format that inspired the structure of this course.
- [aprendago](https://github.com/vkorbes/aprendago) — a Go course in Portuguese whose topic ordering and naming style influenced several chapters here.
